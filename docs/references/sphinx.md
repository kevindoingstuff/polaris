# Sphinx mode

Sphinx mode is on when the repo is Python (a `pyproject.toml` or a top-level package). The docs are MyST markdown that `sphinx-build` renders; they also read as plain markdown on GitHub. Any other language runs plain mode: `docs/README.md` as the index, `> **Note:**` callouts, diagrams under `docs/diagrams/`.

Paths in Sphinx mode:

| What | Path |
|---|---|
| Index | `docs/index.md` |
| Module doc | `docs/<module>.md` |
| Guide page | `docs/get_started.md` (optional, user-written, never regenerated) |
| Diagrams | `docs/_static/diagrams/<module>/*.drawio` and `.drawio.png`, the system map at `docs/_static/diagrams/system.drawio` |
| API reference | `docs/reference/api.rst` |
| Config | `docs/conf.py` |

## Scaffold

Only when `docs/conf.py` is absent. Write the three files below, then add the doc dependencies. `pyproject.toml` present: a `docs` group under `[dependency-groups]` (uv, PEP 735) with `sphinx`, `myst-parser`, `sphinx-design`, `sphinx-copybutton`, `furo`; the group exists: add the missing names only. No `pyproject.toml`: write `docs/requirements.txt` with the same five. Never touch the project's own dependencies.

`docs/conf.py`, `<project>` from `pyproject.toml` `[project] name` or the repo folder, `<src>` the folder that holds the top-level packages (`src` or `.`):

```python
"""Sphinx configuration. Generated by /docs; edit freely, /docs never rewrites it."""

import os
import sys

sys.path.insert(0, os.path.abspath("../<src>"))

project = "<project>"
extensions = [
    "myst_parser",
    "sphinx_design",
    "sphinx_copybutton",
    "sphinx.ext.autodoc",
    "sphinx.ext.autosummary",
    "sphinx.ext.napoleon",
    "sphinx.ext.viewcode",
]
autosummary_generate = True
autodoc_default_options = {"members": True, "undoc-members": True, "show-inheritance": True}
autodoc_mock_imports = [<third-party imports the packages make, as strings>]
myst_enable_extensions = ["colon_fence"]
myst_heading_anchors = 3
exclude_patterns = ["_build", "Thumbs.db", ".DS_Store"]
html_theme = "furo"
html_static_path = ["_static"]
```

`autodoc_mock_imports`: every third-party import across the modules (heavy ones like `torch` would otherwise fail the build); the stdlib and the repo's own packages stay out.

`docs/reference/api.rst`, one line per module id as an import path (`preprocessing`, `training.stage1_mask_rcnn`); a module whose folder has no `__init__.py` is listed by its scripts' parent package when one exists, else left out:

```rst
API reference
=============

.. autosummary::
    :toctree: generated
    :recursive:

    <import path>
```

Build command, for the report line: `sphinx-build -b html docs docs/_build`.

## Existing setup

`docs/conf.py` present: write only `docs/<module>.md` and the diagrams; leave `conf.py`, `index.md` (when it has no stamp), and `api.rst` alone. After writing, read every `{toctree}` in `docs/index.md`; each module doc none of them lists gets one warning line: `index: docs/index.md does not list preprocessing.md`. `html_static_path` missing `_static`: one warning line.

## The guide page

`docs/get_started.md` is written once, from the user's answers, and never regenerated. Shape:

````markdown
# Get started

## Set up your environment

<The user's setup answer as numbered steps. Each tool, credential, or proxy the user names is one step.>

## Run your first task

<The user's first-task answer as numbered steps. The commands come from the code: cite each with a trailing comment.>

You should see: <the expected result the user described>.
````
